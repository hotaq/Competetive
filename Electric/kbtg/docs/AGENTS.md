# KBTG Hackathon — Research & Ideas (docs/)

Rules in this file apply **only to the `docs/` directory** (research, ideas, brainstorming for the KBTG hackathon).

## Event Context

ผู้สมัครทุกคนได้รับโจทย์หลักเดียวกัน แต่ในวันแข่งขันจะถูกแบ่งเป็น 3 Tracks ตามสายงานที่สมัคร

**Hack Challenge:** คิด Feature, Function หรือ Solution ใหม่สำหรับ K PLUS ที่ช่วยให้กลุ่ม **First Jobbers** สามารถ

1. บริหารจัดการเงินและเก็บออมได้ดีขึ้น
2. ลดความเสี่ยงและป้องกันการตกเป็นเหยื่อของ Scam หรือ Fraud

### Tracks

- **Track 1: Software Engineering & Quality** — Software Engineer, AI & Software Testing, Test Engineer. นำเสนอ: จะ Develop อย่างไร → จะ Test / Ensure Quality อย่างไร
- **Track 2: Data Science & Intelligence** — Data Science. นำเสนอ Feature/Solution ที่นำ **Data, Analytics หรือ Intelligence** มาช่วยให้ First Jobbers ตัดสินใจทางการเงินได้ดีขึ้น
- **Track 3: Cyber Security & Digital Trust** — Cyber Security. ป้องกันความเสี่ยง, ตรวจจับธุรกรรมน่าสงสัย, แจ้งเตือนก่อนเกิดความเสียหาย, สร้างความเชื่อมั่นใน Digital Banking

## Our Focus: Track 2 — Data Science & Intelligence

ทุกงานวิจัย/ไอเดียใน `docs/` ต้องมองผ่านเลนส์ของ **Data Science**:

- ใช้ **Data, Analytics, หรือ Intelligence** เป็นแกนหลักของ Solution
- เป้าหมาย: ทำให้ First Jobbers **ตัดสินใจทางการเงินได้ดีขึ้น** (money management, saving, risk/fraud awareness ผ่านมุม data-driven)
- ผู้ประเมินพิจารณา: ความเข้าใจปัญหา, ความเหมาะสมของ Solution, และการประยุกต์ใช้ทักษะ Data Science

## Rules for this directory

1. **เนื้อหาใน `docs/` เป็นงานวิจัย/ไอเดียเท่านั้น** — ไม่ใช่ production code
2. ทุกไอเดียต้องระบุให้ชัดว่าใช้ data/analytics/intelligence อย่างไร (model, features, data source ที่สมมติได้, metrics)
3. โจทย์หลักต้องอ้างอิงกลุ่มเป้าหมาย **First Jobbers** (พฤติกรรมการเงินช่วงเริ่มทำงาน, รายได้ครั้งแรก, ประสบการณ์การธนาคารน้อย)
4. Scam/Fraud สามารถอยู่ในมุม Track 2 ได้ แต่ต้องนำเสนอผ่าน **data/analytics lens** (เช่น anomaly detection, behavioral scoring) ไม่ใช่ security controls เป็นหลัก
5. ไฟล์ใช้โครงสร้าง: `ideas/` (ไอเดีย solution), `research/` (ข้อมูล, บริบท, อ้างอิง) — ตั้งชื่อไฟล์เป็น `kebab-case`
6. ภาษา: เขียนอังกฤษเป็นหลัก ใส่ไทยได้เมื่อช่วยให้ context ชัดขึ้น
7. ทุกไอเดียควรมี: Problem, Target User Insight, Data/ML Approach, How it helps decision-making, Risks/Limitations
8. อ้างอิงความจริงจากแหล่งภายนอก ให้ระบุที่มา (URL หรือชื่อแหล่ง) ไว้ใน `research/`
