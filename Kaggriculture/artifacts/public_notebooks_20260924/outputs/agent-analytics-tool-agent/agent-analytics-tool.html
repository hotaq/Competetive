What's in each tab?

Match — the default tab — is the per-match view: projected value over time, revenue/spend, planting and buying rates, computed for whichever loaded match you pick.

Worlds & Structure — the hardcoded schedule and value-by-day across every loaded game (losses shown reddish, for context, not filtered out), the per-step command-agreement overlay, the 64 shop-pair worlds grid, and the population-level divergence/common-action statistics.

Aggregate charts (not the Match tab, which shows one picked match at a time) are computed from this agent's wins only — a pattern that shows up in a loss is a losing pattern, and letting it into the same vote as a winning one would steer the reading toward what doesn't work.

Projected final score —

Cash in hand plus every harvest/product already visible on the board, priced at what it'll actually be worth on the day it sells — not a snapshot of money right now, a projection of where the match ends up if both sides just keep playing out what's already in motion. The dashed vertical line marks when the lead locks in: the last step (from day 9 on — the fixed opener before that isn't a real signal yet) where this projection still favored the eventual LOSER or was tied. After that point, the projection never flips back for the rest of the match — it's not "where strategies diverge," it's "as of here, the outcome stops being in doubt by this metric."

Idle hands & empty tiles

Idle: hands (plus the main farmer) whose action that turn was literally PASS. Empty tiles: currently unplanted, unlocked land. "Missed" prices the single best crop that could have been planted on each empty tile right now, at today's market price, minus its seed cost — an upper-bound signal ("was there any profitable option sitting idle"), not a precise forecast, since planting the same crop on every empty tile at once would crash its own price the same way a real monoculture does elsewhere in this project.

What's worth planting right now

$/day for each crop if planted on one tile this instant: revenue at a lightly-smoothed market price (a trailing 1-day average — the raw per-step price jumps around on every sale) minus seed cost, divided by the real time from planting to the last harvest that fits before day 30. A line stops where it hits zero remaining time for that crop to produce anything at all — not a fade-out, a hard cutoff, same rule validated on carrot earlier. Below the zero line means planting it would lose money outright, even before accounting for the risk of a crowded market crashing the price further. The line itself is shared (same market, same calendar for both sides) — stacked into two charts below, one per side, just so real bought/planted/sold markers from each side don't sit on top of each other. Each marker is a distinct shape, shade of that crop's own color, AND outline color (dark red = bought, black = planted, dark blue = sold) — nudged a few px apart on the x-axis so a same-step overlap (e.g. buying seed and planting it on the same tick) doesn't hide either one: pale ▼ = bought seed, full-strength ■ = planted, dark ▲ = sold.

What's worth buying right now

Same idea as the crop chart above, for livestock: $/day if a GOOSE/COW/SHEEP were bought and placed on a structure this instant, assuming it stays fed (there's no monetary feed cost in this game — FEED is a free worker action, same as watering a crop). The biggest single pattern

Finds the single largest group of games that played a byte-identical complete action bundle at one step — capped at 60% of that step's games, so this is a real competing pattern, not just "everyone except one or two stray outliers". Then re-runs the "commands common to every game" chart above, scoped to just that group, across the whole match: does its own agreement hold up before and after the step where it was found, or was that one moment a coincidence?

Do the shops explain the forks?

"World" here means the shop configuration, same as the rest of this project — not the seed. Every match unlocks exactly one new shop at the exact same steps (72, 144, 216, 288, 360, 432, 504, 576 — confirmed identical across every real match checked), so the game splits cleanly into 9 fixed phases. Per phase: group games by the exact shop sequence revealed so far, compare each group's OWN divergence during that phase against everyone's unconditioned divergence over the same phase. "Explained" near 100% means the shops themselves account for that phase's fork; low or missing means something else does — most likely the opponent — or (later phases) there just aren't enough games sharing the same shop combination left to test it.

Which matches most increase diversity

Repeatedly removes whichever single remaining game is currently doing the most to suppress how many commands are common to the whole group, worst offender first — not a threshold or a majority vote, the exact same literal-match standard as the chart above. What's left after peeling away the worst offenders is the largest core of mutually similar games; the curve below shows how much more common ground that core has as the outliers are set aside. Not computed for the combined pool (too many games for this to finish in reasonable time) — pick a single player on the left.

Worst offenders — removed first, in order; "gain" = how many more common commands the group would have without this one game

Divergence and "distinct lines" fingerprint a step as (farmer op, hand count, sorted hand ops, sorted market op types) — the whole step as one bundle, so one differing hand makes the entire step count as different. "Commands common to every game" instead looks at each worker/order independently and keeps only the commands present in literally every game that step — a much stricter, but more forgiving-to-partial-agreement, view of the same data. Both collapse all four move directions into one "MOVE" class first — the board layout is randomized per match, so raw compass directions would just measure map noise, not strategy. Everything runs locally in this tab — pick the folder again any time you have more games, and it recomputes on the spot.
